# 🎨 ColoKid 儿童色彩乐园

面向 **3–7 岁儿童**的色彩认知与配色启蒙桌面应用。按 **认色 → 辨色 → 调色 → 配色 → 用色** 五个递进阶段构建，全部数据保存在本机浏览器 IndexedDB，**完全离线、零网络请求、构建产物自包含**。

## ✨ 六大模块

| 模块 | 路由 | 内容 |
| --- | --- | --- |
| 认色卡 | `/colors`、`/color/:id` | 12 色大色块、名称、拼音、TTS 朗读、生活例子、明度/饱和度渐变 |
| 辨色游戏 | `/game/discriminate` | 多色块找指定色；进阶含深蓝浅蓝、红橙、黄绿、紫粉等相近色辨析 |
| 调色实验室 | `/lab` | 红黄蓝+黑白五颜料拖拽混合，Canvas 实时真实混色，目标挑战 + CIEDE2000 ΔE 色差鼓励，保存配方 |
| 配色练习 | `/match` | 50 题：20 两色（互补/邻近）+ 20 三色（三角/分裂互补）+ 10 主题配色，规则判定与解释，完成后给简笔画上色 |
| 情境用色 | `/color-in` | 30 个真实情境（10 场景 × 3 情绪），点击/拖拽填色表达情绪，保存作品与一句话说明 |
| 色彩观察日记 | `/diary` | 文字 + Canvas 涂鸦 + 拍照，颜色标签，按日期时间线，TTS 朗读 |

另有：`/home` 首页、`/gallery` 我的作品、`/reward` 星星与徽章、`/parent` 家长面板（4 位 PIN）。

## 🧠 色彩引擎（纯本地计算）

- **真实颜料混色**（`src/lib/mixEngine.js`）：RYB 传统美术模型，红/黄/蓝大三角形六分三角形重心插值求彩色基底，再在线性 RGB 空间与黑/白调暗调亮。红+黄=橙、蓝+黄=绿、红+蓝=紫、等量三色=棕，共内置 20 组配方。
- **CIEDE2000 色差**（`src/lib/colorMath.js`）：sRGB→Lab 完整实现，调色实验室用 ΔE 给出“一模一样/非常接近/再试一滴”的温和鼓励。
- **配色规则**（`src/lib/colorWheel.js`）：互补色、邻近色、三角配色、分裂互补，含可交互 SVG 色轮。
- 题库答案均由规则引擎计算验证（见 `scripts/logic.test.mjs`）。

## 🏅 激励系统

- 认色卡 1 星；辨色正确率 ≥80% 得 1 星、100% 得 2 星；调色/配色/情境/日记各 1 星。
- 六枚徽章：**认色达人（12 色）、辨色高手（90%）、调色小魔术师（20 次）、配色设计师（30 个）、色彩观察家（30 篇）、色彩表达者（10 幅）**。
- 星星阶梯解锁贴纸墙。

## 👪 家长面板

- 4 位 PIN（默认 `0000`，首次进入醒目提示修改；**SHA-256 加盐哈希**存储，无明文）。
- PIN 错误无法进入，也无法修改任何设置。
- 可查看：认色进度、辨色正确率与**易错色 TOP5**、调色配方、配色/情境作品、观察日记、学习时长。
- 可调整：每日练习量（3–10 题，默认 5）、音效与语音开关、修改 PIN、重置进度、删除档案（删档案二次 PIN 确认）。
- JSON 导出/导入（单孩子或全部备份）。

## 🧒 幼儿友好设计

- 大色块占屏 60%+、正文 ≥20px、按钮文字 ≥24px、色名 ≥48px、按钮 ≥80×80px、圆润卡通、按压缩放反馈。
- **无倒计时、无失败惩罚**；答错温和引导（“再看看～”）并可立即重试；误触可返回。
- 关键操作中文 TTS（Web Speech API），无语音或静音时静默降级、照常可玩；音效为构建期生成的本地 WAV（data URI，无音频文件外链）。
- 答对即时反馈实测 **20–50ms**（远优于 <500ms 要求）。
- 多玩家档案，进度按 `profileId` 严格隔离（E2E 已验证两儿童切换不串）。

## 🛠️ 技术栈

React 18 + React Router（HashRouter，静态托管免 fallback 配置）+ Zustand + Tailwind CSS + SVG 插画 + Canvas（混色/涂鸦）+ Web Speech API + IndexedDB（9 个对象仓库）。

**禁止项已落实**：无 `fetch`/`axios`/XHR、无 CDN、无外部图片/字体/音频，所有资源本地内置或由代码生成。

## 🚀 本地开发

```bash
npm install
npm run dev        # http://localhost:1420
```

## 🐳 Docker 一键运行（推荐）

```bash
docker compose up --build
# 浏览器访问 http://localhost:1420
```

- 多阶段构建：`node:20-alpine` 构建 → `nginx:1.27-alpine` 托管，监听并映射 **1420** 端口。
- 数据保存在浏览器 IndexedDB；支持家长面板导出/导入 JSON。
- 清空容器与卷：`docker compose down -v`（IndexedDB 数据在浏览器本地，不含在卷内）。

```
  store/       # Zustand：appStore（玩家/设置/PIN/徽章）、progressStore（学习数据）
  components/  # 按钮、色块、色轮、SVG 场景/简笔画、Canvas 涂鸦板、反馈/徽章弹窗

```
